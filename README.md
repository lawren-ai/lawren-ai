## 🎯 Featured Projects

### 📈 [AlphaOpt](https://github.com/lawren-ai/alpha-opt) | [🌐 Live API](https://alpha-opt.onrender.com/docs)
A comprehensive production-grade portfolio optimization and options pricing platform with REST API, real-time market data integration, and interactive visualizations. Features include Mean-Variance Optimization (Markowitz), Black-Scholes options pricing with full Greeks calculations, Monte Carlo simulations, and efficient frontier visualization. Deployed on Render with Docker containerization and sub-200ms response times.

**Tech**: Python • FastAPI • NumPy • SciPy • Streamlit • Docker • yfinance • Plotly

---

### 🎬 [Netflix Recommendation Engine](https://github.com/lawren-ai/Netflix-Recommendation-Engine)
A sophisticated content-based recommender system that delivers personalized movie and series suggestions using similarity metrics and NLP techniques. Analyzes user preferences and media metadata to create Netflix-style recommendations.

**Tech**: Python • Pandas • scikit-learn • NLP • Cosine Similarity

---

### 📊 [Customer Churn Predictor](https://github.com/lawren-ai/customer-churn-predictor)
An end-to-end ML pipeline for predicting customer attrition with comprehensive data analysis, feature engineering, model training, and evaluation. Empowers businesses to proactively identify at-risk customers and reduce churn.

**Tech**: Python • scikit-learn • Data Preprocessing • Classification Models • Feature Engineering
